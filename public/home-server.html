Home Server

A self-hosted infrastructure platform built from repurposed components — running a headless Debian OS, fully containerized with Docker, and serving as the backbone of my personal media, storage, and development ecosystem.

Debian Linux Docker Portainer Virtual Machines
Overview

What it is

Built from repurposed components, this home server runs a headless Debian OS and serves as the backbone of my personal infrastructure. All services are containerized using Docker and managed through Portainer, keeping the system modular, maintainable, and easy to update.

The server pulls double duty as both a storage solution and a media platform — hosting a full Plex library spanning movies, TV shows, and audiobooks, alongside Calibre for e-book management. Kasam provides a virtualization layer for development and testing in isolated VM environments. Homarr ties everything together as a clean, centralized dashboard for high-level access and monitoring.

Beyond media and storage, the server also acts as the hosting environment for several of my personal projects — putting the infrastructure to practical use and giving me a real-world platform to build, test, and iterate against.

Services

Running Containers

Plex Media Server

Streams a curated library of movies, TV shows, and audiobooks to any device on or off the network. Handles transcoding, metadata, and multi-user watch history automatically.

Calibre

Full e-book library management with format conversion, metadata editing, and a built-in content server for wireless syncing to any reader or device.

Kasam

Provides a lightweight virtualization layer for spinning up isolated VM environments. Used for development, testing, and sandboxing without needing separate physical hardware.

Homarr

A centralized, customizable dashboard that aggregates all services into a single pane of glass. Provides quick access links, status indicators, and at-a-glance monitoring across the entire stack.

Portainer

Web-based Docker management interface for monitoring container health, viewing logs, managing images and volumes, and deploying updates — all without touching the command line.

Personal Project Hosting

Several of my personal software projects run as containers on the server, giving me a real-world deployment environment for iterating on and testing builds outside of a local dev machine.

Technical

Stack & Architecture

Hardware

Assembled from repurposed consumer components — purpose-built to run headless 24/7 with a low enough power draw to be cost-effective as always-on infrastructure.

Operating System

Headless Debian Linux. No GUI overhead — all management is done via SSH or web-based interfaces. Chosen for its stability, long release cycles, and broad Docker support.

Containerization

Every service runs as an isolated Docker container. Compose files define the stack declaratively, making the entire setup version-controlled, portable, and reproducible from scratch.

Storage

Local storage serves the media library and container volumes. Organized directory structure separates persistent config data from media, making backups and migrations straightforward.

Networking

Services are isolated on a Docker bridge network with only necessary ports exposed. Remote access is handled securely, keeping the attack surface minimal.

Maintenance

Portainer handles day-to-day container management. Updates are rolling — containers are pulled and restarted individually, keeping downtime effectively zero for any single service.
