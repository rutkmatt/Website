AI Gardener

Born from a passion for cooking and the challenge of maintaining fresh herbs amid a demanding schedule, this project combines hardware and AI to create a fully autonomous indoor herb garden system. Built on a Raspberry Pi with an IR camera and a lightweight on-device AI model, the system independently manages watering, lighting, and nutrient delivery. A generated weekly report provides a full health summary — covering plant condition, resource levels, and flagged areas for review.

Recipe Manager

A full-stack desktop application built with Python, PySide6, and SQLAlchemy. Features a searchable and filterable recipe library, an interactive meal planning calendar, and a recipe detail view with ingredient check-off, step-by-step instructions, and nutritional tracking. Supports recipe import from multiple sources and integrates with Google Calendar and a smart shopping list service — with custom logic to filter staples and handle user confirmation before syncing. Personal notes, images, and reviews can be attached to any recipe. Designed with a normalized relational database schema and a clean repository pattern separating data access from UI logic.
