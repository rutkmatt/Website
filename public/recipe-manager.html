Recipe Manager

A full-stack desktop application for managing recipes, planning meals, and automating grocery lists — built with Python, PySide6, and SQLAlchemy.

Python PySide6 Qt SQLAlchemy SQLite Google Calendar API
This project is currently under active development. Screenshots, demos, and full documentation will be added as the project matures.
Overview

What it does

A full-stack desktop application built with Python, PySide6, and SQLAlchemy. Features a searchable and filterable recipe library, an interactive meal planning calendar, and a recipe detail view with ingredient check-off, step-by-step instructions, and nutritional tracking. Supports recipe import from multiple sources and integrates with Google Calendar and a smart shopping list service.

Features

Key Capabilities

Recipe Library

Searchable and filterable recipe library with tagging, ratings, and personal notes. Import from multiple sources.

Meal Planner

Interactive weekly and monthly calendar for planning meals. Syncs with Google Calendar for full schedule integration.

Smart Shopping List

Auto-generated shopping lists from meal plans with custom logic to filter pantry staples and handle user confirmation before syncing.

Nutritional Tracking

Per-recipe nutritional breakdowns with macros and micronutrients. Tracks intake across a meal plan period.

Clean Architecture

Normalized relational schema with SQLAlchemy ORM. Repository pattern cleanly separates data access from UI logic.

Attachments & Notes

Attach personal notes, photos, and reviews to any recipe. Full history of modifications and substitutions.

Technical

Architecture & Design

Stack

Python · PySide6 (Qt) · SQLAlchemy ORM · SQLite · Google Calendar API

Data Model

Normalized relational schema. Recipes, ingredients, tags, meal plan entries, and shopping list items stored relationally with foreign key constraints.

Architecture

Repository pattern separates data access from UI logic. Qt model/view pattern drives the recipe and calendar interfaces.

Integrations

Google Calendar OAuth 2.0 for meal plan sync. Pluggable shopping list service with per-item confirmation flow.
